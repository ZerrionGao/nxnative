# 无双大蛇 2 终极版（`0100153006300000`）

打包与排错见 [移植说明.md](移植说明.md) 与仓库根目录 [PORTING.zh.md](../../PORTING.zh.md)。

## 打好包之后

- Mac 应用默认输出：`artifacts/apps/WarriorsOrochi3U.app`
- 这张日文卡带只有日文游戏数据。可将 `Info.plist` 的 `DMLanguage` 设为 `zh-Hans` 使启动窗为中文；游戏内文字仍是日文。
- 跳过启动窗：

```sh
open ./artifacts/apps/WarriorsOrochi3U.app --args --no-launcher
```

- 存档：`~/Library/Application Support/nxnative/0100153006300000/`
- 日志：`~/Library/Logs/nxnative/0100153006300000.log`

SDK 1.6 没有进程内音频渲染器；宿主用软混音播放 PCM / DSP-ADPCM（影片走 AudioOut）。2026-11-10 修复语音缓冲区提交返回值、参数顺序和重采样连续性后，用户已在 iPhone 上确认剧情对白语速与清晰度恢复正常。完整战斗流程和长时运行仍未验收。手机安装请使用你自己的开发者账号，并开启提高内存上限。
